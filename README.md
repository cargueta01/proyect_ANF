# proyect_ANF
Proyecto académico desarrollado para la materia de Análisis Financiero.

La aplicación está construida con Laravel y permite gestionar información financiera empresarial para apoyar el análisis de desempeño. Incluye módulos para:

- Registro de empresas, períodos, sectores y catálogos de cuentas.
- Carga y administración de balances generales y estados de resultados.
- Cálculo de análisis horizontal, análisis vertical y ratios financieros.
- Visualización de resultados y comparación de indicadores.
